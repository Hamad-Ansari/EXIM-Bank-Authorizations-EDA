# EXIM Bank Authorizations EDA & Dashboard (2006 - 2025)

**Comprehensive Exploratory Data Analysis** of all EXIM Bank approved export credit authorizations from October 2006 to June 2025.

This project analyzes **51,753** authorizations with special focus on:
- The EXIM Bank lapse in authority period (2015–2019)
- Multiyear Working Capital Extensions
- Geographic concentration & top export markets
- Program performance and policy trends
<img width="2704" height="1520" alt="bank" src="https://github.com/user-attachments/assets/af2cab95-bea3-476b-955a-94573430be44" />

## Key Objectives

- Understand long-term trends in U.S. export financing
- Analyze impact of the 2015-2019 lapse in authority
- Identify top countries, exporters, and programs
- Evaluate data quality and portfolio concentration risk

## Key Insights & Findings

- Significant drop in authorization volume during the **2015–2019 lapse period**
- 251 Multiyear Working Capital Extensions were processed during the lapse
- High market concentration — Top 3 countries represent a large % of total deals
- Working Capital programs dominate short-term activity
- Notable data quality issues (e.g. 58% missing Primary Lender)

## Features

- Full Exploratory Data Analysis (EDA)
- Rich visualizations using Seaborn & Matplotlib
- Lapse Period Deep Dive Analysis
- Geographic & Financial Exposure Analysis
- Temporal trends & seasonality
- Data quality assessment

## Technologies & Libraries

- **Python 3.9+**
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook
